# **Todo App** #

A simple and interactive Todo App built to practice JavaScript fundamentals, DOM manipulation, event handling, and local data management.


## Features
* ➕ Add new tasks
* ✅ Mark tasks as completed
* 🗑️ Delete tasks
* ✏️ Manage your todo list easily
* 💾 Save todos using Local Storage
* 🔄 Todos remain available after refreshing the page
* 📱 Simple and responsive user interface
